7 · Your data

Your contacts stay yours.

Local only

Everything is stored on the device. OCR runs on the phone. No account, no cloud.

Export anytime

vCard, CSV, and a full backup file. Import from the same formats.

Sync by QR

Scan a QR on the desktop app to pair over local Wi-Fi. The server runs only while the Sync screen is open.

Optional app lock. Card photos have location data removed by default.

Pairing uses a one-time code valid for two minutes and a pinned certificate. It works on a work laptop because nothing is installed as a service.

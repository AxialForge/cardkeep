# Phone test sheet: CardKeep 0.2.1

**Install:** Settings → Updates → **Check for updates** in 0.2.0 should offer 0.2.1 and install it over the top
(the first time, Android asks to allow installs from CardKeep). Your contacts stay. Tick each line; note anything odd.

## Updater (first real in-app update)
- [ ] 0.2.0 finds 0.2.1, shows its notes, downloads with progress, and Android shows "Update".
- [ ] After the update, CardKeep opens with all contacts, cards and the review queue as before.
- [ ] Settings → Updates now says 0.2.1 is the latest.

## Scanner (the 0.2.0 complaint)
- [ ] Hold a card so it fills about half the screen width: it captures without asking you to move closer.
- [ ] No more loop between "Move closer" and "Card cut off".
- [ ] Normal hand shake doesn't restart the countdown; it captures within about a second.
- [ ] A glossy card under a light: it still captures after a short wait (about 1.5 s) and is marked "Glare".
- [ ] Note the distance that felt natural: ______

## Reading animation (new)
- [ ] After a capture an orange line sweeps the card, then the name, title, company, phone and email light up in
  colour with labels beside them.
- [ ] With Android's "Remove animations" on, the highlights appear at once.

## Duplicates (new)
- [ ] Rescan the card of someone already in Contacts and save it: their page shows "Possible duplicate".
- [ ] Drawer → **Duplicates** lists the pair with a reason ("Same mobile number" / "Same name and email" / "Same
  name, similar company").
- [ ] **Compare and merge**: choose the name and title, merge. One contact remains with both cards, all phones and
  emails, and notes from both.
- [ ] **Undo merge** on that page brings both back. (Undo is available until CardKeep is closed.)
- [ ] **Not the same person** removes a pair and it doesn't come back after **Check again**.

## Tags (new)
- [ ] Drawer → **Tags** → **New tag**: name and colour.
- [ ] On a contact's page, Tags → **Add**: tick tags, Done; the coloured chips show.
- [ ] Long-press several contacts → tag button: all get the tag.
- [ ] The tag appears as a filter chip on Contacts; tapping it shows only those people. Searching the tag name finds
  them too.
- [ ] Edit a tag → Delete: it asks first and says how many people have it; the contacts stay.

## Report
Phone model and Android version, any unticked line, the scanning distance, and photos of any card it read badly.

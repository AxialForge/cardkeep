# Phone test sheet: CardKeep 0.3.0

**Install:** Settings → Updates → **Check for updates** should offer 0.3.0 and install it over 0.2.2. Your contacts
stay (the database moves to version 3 on first open). Tick each line; note anything odd.

## Your requests (S10b)
- [ ] Scan a card with an extension ("Ext. 112"): the phone shows "ext. 112"; **Call** dials the number, pauses,
  then the extension.
- [ ] A card with a fax: Fax shows with a printer icon; tapping does nothing, long-press copies it.
- [ ] A card printed in capitals: the name and title come out as "Fred Paneto" / "Plant Manager".
- [ ] A name with a middle initial ("Dana K. Reyes"): the Middle box is filled. On a new contact, **Add middle
  name or initial** shows the box.
- [ ] Slogans, licence numbers, hours, "since 19xx" land under **More from the card**, not in notes.
- [ ] The company logo appears in the contact's circle (list and page). More → **Remove logo** brings the
  initials back. Note any card where it picked the wrong thing: ______
- [ ] Two people from the same company: each page shows **Others at <company>**.
- [ ] Settings → **Lead ratings** off: Hot/Warm/Cold disappear from the list, filters, pages and the edit page.
  The edit page's ⋮ menu turns them back on.
- [ ] **+** on Contacts opens: Scan a card, Scan a stack, Add by hand, Import card photos. Each works.
- [ ] Sort by **first name** (switch under Name, or Settings): the list and A–Z index follow it.
- [ ] Settings → Appearance: **Navy and brass dark** looks right; Medium is gone.

- [ ] The event page's goal ring and counts go up. **End session** stops new cards joining it.

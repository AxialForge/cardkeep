# Phone test sheet: CardKeep 0.1.1

Install `CardKeep-0.1.1-arm64-v8a.apk` from the GitHub Release. Tick each line; note anything odd next to it.
Everything here already passed on the emulator; this sheet covers what only a real phone shows.

## Install and look
- [ ] The app installs from the Release APK and the launcher shows the orange CardKeep icon and the name "CardKeep".
- [ ] With themed icons on (Wallpaper & style → Themed icons), the icon turns monochrome.
- [ ] Fonts look like the mockups (serif headings, clean sans-serif text). Nothing is cut off.

## Themes (new in 0.1.1)
- [ ] First launch follows your phone: light mode gives the white Light theme, dark mode gives the black Dark theme.
- [ ] With CardKeep open, switch the phone's dark mode on and off (quick settings): the app follows straight away.
- [ ] Settings → Appearance: pick Light, Medium, Dark and Navy and brass in turn; every screen changes at once.
- [ ] In Dark, all text and buttons are readable (Add phone, Set, Add note, menus, date picker).
- [ ] Close and reopen CardKeep: your chosen theme is still selected.

## Contacts
- [ ] Add 3 real contacts by hand (your own details or colleagues'). The phone line shows "Saved as +1 …".
- [ ] Each contact opens after Save; Back returns to the list.
- [ ] Search finds them by first name, company, email, and the last 4 digits of a phone number.
- [ ] Sort by Company and by Recent; the A–Z strip appears once you have more than 20 contacts.
- [ ] Hot/Warm/Cold chips filter the list.

## Actions (the parts the emulator can't really do)
- [ ] **Call** opens your dialer with the number filled in.
- [ ] **Message** opens your messaging app to that number.
- [ ] **Email** opens your mail app with the address filled in.
- [ ] Tapping the website opens your default browser (not inside CardKeep).
- [ ] Tapping the address opens your maps app.
- [ ] **Check on web** opens a search for the name and company in your default browser.
- [ ] **Share** sends a .vcf; opening it on another phone or in Google Contacts shows the right details.

## Editing and safety
- [ ] Edit a contact, remove a phone, Save: the phone is gone, the rest is unchanged.
- [ ] Change something, press Back: CardKeep asks before discarding.
- [ ] Delete a contact, tap **Undo**: it comes back.
- [ ] Long-press two contacts, set them Hot from the bottom bar.

## Phone behaviour
- [ ] Back with the menu open closes the menu (does not leave the app).
- [ ] Phone text size at its largest (Settings → Display → Font size): screens still readable, nothing overlaps.
- [ ] Rotate is not needed (portrait app) — note if anything breaks if it does rotate.
- [ ] Close CardKeep from recents and reopen: contacts are still there.

## Debug OCR capture (debug builds only; skip on the Release APK)
- [ ] Not in the drawer of the Release APK.

## Report
Send back: phone model and Android version, any unticked line, and screenshots of anything that looks wrong.

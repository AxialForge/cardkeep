# Phone test sheet: CardKeep 0.5.0

**Install:** Settings → Updates → **Check for updates** offers 0.5.0. Your contacts stay.

## Back up first (new)
- [ ] Drawer → **Export and backup** → Backup → **Save to…**: choose Google Drive or Downloads. The zip is saved.
- [ ] Turn on **Weekly backup on this phone**; close and reopen CardKeep: a backup appears in the list under it.

## Export (new)
- [ ] Export **Everyone** as vCard 3.0 → Share → e.g. email it to yourself; open it on a computer: everyone is there,
  with extensions ("x112") and fax numbers.
- [ ] Export a tag or an event as **HubSpot CSV** → Save to…; open it in Excel or Google Sheets: names and accents
  read correctly.
- [ ] **Include card photos** makes a .zip with the card images.

## Import (new)
- [ ] Export your Google or Outlook contacts as .vcf and import a few: "N new, N updated, N already there". Imported
  people have the **Imported** tag; someone you already had isn't added twice.
- [ ] Open a .vcf from an email or the Files app → **Open with CardKeep**: the import starts.
- [ ] Import a .csv: the column screen guesses the columns; fix one, check the preview, Import. Importing a file with
  the same columns again remembers your choices.

## Restore (new; do this after a backup)
- [ ] Import → **CardKeep backup (.zip)** → pick your backup: it shows the date and counts and asks first. CardKeep
  closes; open it again: everything is as it was at the backup.

## My card (new)
- [ ] Drawer → **My card** → Add my details. The QR code shows; tap it: full screen and full brightness. Scan it with
  another phone's camera: it offers to add you as a contact.
- [ ] **Share as contact file** sends a .vcf.

## Report
Phone model, any unticked line, and any file that imported badly (send the file if you can).

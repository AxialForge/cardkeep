# Documentation

Finished PDF and Word documents for CardKeep, named `<Document name> Rev x.y`.

- One subfolder per app version (`0.6.2/`, `0.6.1/` ...): every document made for that release goes in its folder.
- Project-wide documents that are not tied to a release (the roadmap) stay here at the top.
- A rebuild of the same document is the next Rev in the same folder; older revisions are kept.
